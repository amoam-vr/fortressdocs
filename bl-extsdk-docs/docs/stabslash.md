# Stab Slash
Gives a `Marrow Entity` (a spawnable) the ability to stab and damage enemies and certain spawnables. Also can be used to inflict blunt damage.

## Requirements
A `Stab Slash` **must** be on the same `GameObject` as a `Marrow Entity`.
