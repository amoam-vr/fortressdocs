# BONELAB EXT SDK Documentation
For BONELAB SDK modders using notnotnotswipez's Extended SDK.
Written by AMOAM (and others but mainly AMOAM did the whole thing, thanks AMOAM)

## Introduction
This documentation will attempt to list everything relating to all scripts included in [notnotnotswipez's Extended SDK](https://github.com/notnotnotswipez/Marrow-ExtendedSDK-MAINTAINED).

Each script documentation will have this structure: 
<ul>
    <li>What the script does and how it's used</li>
    <li>Script requirements</li>
    <li>An image example of the script</li>
    <li>All the usable properties and what they affect</li>
    <li>Other useful advice regarding the script</li>
</ul>
