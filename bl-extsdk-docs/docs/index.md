# BONELAB EXT SDK Documentation
For BONELAB SDK modders using notnotnotswipez's Extended SDK.
Written by AMOAM and hopefully more people in the future.

## Introduction
This documentation will attempt to break down everything relating to all scripts included in [notnotnotswipez's Extended SDK](https://github.com/notnotnotswipez/Marrow-ExtendedSDK-MAINTAINED).

Each script documentation will have this structure: 
<ul>
    <li>What the script does, how it's used, and other unique information</li>
    <li>Script requirements</li>
    <li>An image example of the script</li>
    <li>All the usable properties and what they affect</li>
</ul>
