# Evil Sealters Script
Gives a `Sealters Body` the ability to kill everyone and slime em all out onf (on faits)

## Requirements
An `Evil Sealters Script` cannot exist on the same `Sealters Body` as a `Good Sealters Script`

An `Evil Sealters Script` must be given a blood sacrifice (preferably from [Eirthos](https://www.youtube.com/@eirthos))
